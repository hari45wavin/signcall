# Demo script (draft, ~3 min)

1. **Problem (20 s).** Video calls leave signers out: others can't read sign, and live interpreters are rare.
2. **Join (20 s).** Create a room, share the link, second laptop joins as a guest.
3. **Sign Mode (60 s).** Signer turns on Sign Mode, fingerspells a name, signs 2–3 vocabulary words. Captions appear for everyone; the sentence is read aloud.
4. **Reply (30 s).** Hearing participant answers; signer reads the transcript (or types back).
5. **How it works (30 s).** One slide: landmarks in the browser → classifier → captions over the data channel.
6. **What's next (20 s).** More vocabulary, in-browser model, voice injected into the call, saved transcripts.

Backup: a pre-recorded video of the full flow in case the venue Wi-Fi fails.

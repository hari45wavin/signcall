## Style: minimal light

| Token | Value |
|---|---|
| Accent | `#2F62E8` |
| Leave / danger | coral |
| Background | white, soft grey panels |
| UI font | Plus Jakarta Sans |
| Caption / transcript font | Atkinson Hyperlegible |
| Caption size | adjustable 22–44 px |

Accessibility: WCAG AA contrast, captions are the most readable thing on screen, keyboard shortcuts, respect reduced motion.
